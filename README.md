# ビールジョッキ

![注いでいる途中・注ぎ終わり・30° 傾けたところ・飲んでいるところ](screenshot-states.png)

スマホそのものをビールジョッキに見立てるブラウザアプリです。
開くと画面いっぱいのジョッキに、ビールが泡と一緒に注がれます。
スマホを傾けると液面は水平を保ったまま動き、縁を越えたぶんが「ゴクゴク」と飲まれて減っていきます。

ガラスの屈折、ビールの琥珀色、泡、液の中を上る炭酸の泡までを、1 枚のフラグメントシェーダーでレイトレースして描いています。
[three.js](https://threejs.org) と [Vite](https://vite.dev) で作りました。
作り方は同じ作者の [ラムネ](https://github.com/Kawade502/ramume) を土台にしています。

## 動かし方

```bash
npm install
npm run dev
```

http://localhost:5184 を開きます。

公開版：https://kawade502.github.io/beer-jug/ （`main` に push すると [GitHub Actions](.github/workflows/pages.yml) が自動でビルドして公開します）

Facebook・X・LINE などに URL を貼ると、[`public/og.jpg`](public/og.jpg)（1200×630）がプレビューの画像として出ます（`index.html` の OGP と X のタグ）。

- 各サービスは画像を URL ごとに覚えておく。画像を変えたら、ファイル名を変え（`og-2.jpg` など。前の画像は消さない）、`index.html` の `og:image` と `scripts/og.mjs` の書き出し先も合わせる
- Facebook は[シェアデバッガー](https://developers.facebook.com/tools/debug/)で「再スクレイピング」すると読み直す
- X は投稿欄に URL を貼ると（投稿しなくても）プレビューを見られる。古いままなら、URL の後ろに `?v=2` を付けて貼る

| 操作 | 動き |
| --- | --- |
| 開く | 空のジョッキにビールが注がれる |
| 「乾杯！」をタップ | 音が出るようになり、スマホでは傾きセンサーを使い始める（iPhone は許可を聞かれる）。そのときの持ち方を「まっすぐ」とみなす |
| スマホを傾ける | 前後左右どちらに傾けても、液面と泡は水平のまま。縁を越えると飲める |
| スマホを振る（パソコンでは素早く左右にドラッグ、または **S**） | ビールの一部が泡に変わり、泡の頭が立つ。泡は縁の少し上まで |
| 右上の水平器ボタン | 今の持ち方を「まっすぐ」にし直す |
| ドラッグ、または **←** **→** **↑** **↓** | パソコンで傾ける（左右と前後）。ジョッキそのものが画面の上で傾き、液面は水平のまま。離すと揺れながら戻る |
| 「おかわり」、または **R** | もう一杯注ぐ |
| **M**、または右上のボタン | 音を消す／出す |

## 仕組み

**ジョッキ = スマホ。** ジョッキのローカル座標をスマホ本体と同じ向き（x 右、y 上、z 手前）にして、カメラは本体に固定しています。
スマホを傾けて変わるのは「重力の上向き」だけです。[`src/tilt.js`](src/tilt.js) が傾きセンサーの beta/gamma から本体の座標での上向きを出します。

- 傾けると OS が画面を自動で横向きにするが、そのぶん中身を逆に回すので、ジョッキは本体に貼り付いたまま。ブラウザが画面をほぼ埋めているときは、横向きかどうかを画面の形（横長か）で決める（iPhone は回る途中で角度の値が古いことがあるため）。画面分割や小さなウインドウでは角度で決める。どちらへ倒したかは重力の向きで決める
  - 逆に回している間も、ジョッキの大きさ（1mm あたりの画素数）は縦向きのときと同じにし、ノッチなどの余白は本体の辺に合わせて付け替える
  - センサーがない間（乾杯の前、許可されなかったとき）は OS の回転だけが重力の手がかりなので、逆に回さない。乾杯の前に横向きにすると、縦に持って乾杯するよう案内する
  - 自然な向きが横のタブレットでは、逆に回さず、センサーの値を画面の向きへ回す
- Android の Chrome などでは、乾杯したときに全画面にして縦向きに固定する
- iPhone は回転を止められないので、画面がいったん回ってから戻る。一度だけ「画面縦向きのロック」を案内する
- 持ち方の補正は、画面がどれだけ寝ているか（重力の画面に垂直な成分）だけで決めるので、横持ちで乾杯しても縦に戻せばまっすぐになる

- スマホはふだん少し寝かせて持つので、乾杯したときの前後の傾きを「まっすぐ」とみなす（端末の x 軸まわりに回して補正する。方位には関係しない）
- 液面は上向きを、ばねで少し遅れて追う。急に傾けると行き過ぎて何回か行き来し、ちゃぷちゃぷ揺れる
- スマホを横や前後に動かすと、その加速度で液面が揺れる（容器が加速すると液面は「重力 − 加速度」に垂直になる。右へ動かすと左が高くなる）。端末によって加速度の符号が逆なので、重力込みの値と傾きセンサーの向きを比べて合わせる。ゆっくり変わる分（センサーのずれなど）は引いて、揺らした分だけを使う
- 飲む判定は、揺れを含まない向きで決める。揺らしただけで縁を越えて「ゴクゴク」にはならない
- 背景と光は重力の側に固定してあるので、傾けると映り込みが流れる。揺らしたときの揺れは中のビールだけで、背景は動かない
- センサーを使っていないとき（パソコン、センサーを許可しなかったスマホ）は傾ける本体がないので、ドラッグした角度でジョッキそのものを画面の上で回して描く

**液面と泡。** [`src/jug.js`](src/jug.js) は、ラムネと同じく「体積が変わらない水平な面」の高さを二分法で解きます。
ジョッキを高さごとの輪切りにし、それぞれの円が面より下にある部分の面積を足して体積を出します。

- 液面：ビールの体積から
- 泡の上面：ビール＋泡の体積から。立てているときだけ、縁の上に 10mm まで盛り上がれる
- 縁のいちばん低いところ（上向きに測った高さ）を液面が越えたら、越えた高さの 1.5 乗に比例して流れ出る
- 泡はふわっと固まっているので、傾けても流れ出さない。縁を越えた分は縁で切れて見えるだけで、立て直すと泡の頭が戻る。ビールは泡の下をくぐって口に入り、泡の層は液面に乗ったまま下がる

**注ぐ・飲む。** [`src/beer.js`](src/beer.js) が中身を受け持ちます。

- 注ぐ：6.5 秒かけて注ぎ、勢いで泡が立つ。満ちるほど泡の割合が増え、注ぎ終わると 3 秒ほどで落ち着く
- 泡は時間とともに痩せる。1 分で約 5 割、2 分で約 3 割、3 分で約 2 割になり、最後は薄い膜が残る
- 振る：加速度センサー（重力を除いた加速度が 8〜20 m/s²）か、傾きの変わる速さ（7〜14 rad/s。ふつうに傾けて飲む動きや、手を離して戻る動きより速い）で振った強さを測る。振っている間はビール 1 が泡 4 のかさに変わり、液の中も細かい泡で濁る。泡は縁の少し上、注いだときの泡の 1.5 倍までしか立たない
- 注いだ直後はビール全体が細かい泡で濁り、だんだん澄んでいく
- 炭酸：ジョッキの底と壁の決まった場所から、泡が列になって上る
- 飲む：0.5 秒ごとに「ゴクッ」。そのうち 0.34 秒の間だけ縁からビールが流れ込むので、液面が脈打つように下がる
- 残りが 6ml を切ったら「ごちそうさま」

**光。** [`src/shader.js`](src/shader.js) が画面の 1 ピクセルごとに光線を飛ばします。

- 光線は空気→ガラス→ビール→ガラス…と面を越えるたびに、フレネル反射と屈折に分かれる
- ガラスとビールは、通った距離のぶん色を吸収する。ビールは青をよく吸うので、厚いところほど濃い琥珀色になる
- 泡の層は、ガラスに押し付けられた泡の膜の模様（ボロノイ）を描く。0.4mm ほどの細かい泡を、明暗を控えめにしてクリーム状に見せ、液面のすぐ上だけ少し大きな泡とビールの色を混ぜる。泡が画面の画素より小さくなるときは模様を薄めて、ちらつかないようにする
- 液面、炭酸の泡、注ぐ流れは式で直接交点を求め、ガラスと泡の層は距離場をたどって探す
- 光線の行き先は居酒屋。ジョッキの後ろのやわらかく明るい壁、店の明かりのぼけ、木のカウンターがある

**音。** [`src/sound.js`](src/sound.js) は、音声ファイルを使わずに Web Audio で合成しています。

- トクトク：落ちる流れのザーッと、泡のポコポコ。ジョッキの中の空気の共鳴（長さの 4 倍の波長）を通すので、満ちるほど音程が上がる
- シュワシュワ：ごく短い高い音の粒を 1 秒に約 2500 個、大きさをそろえて敷き詰めた、きめ細かい音。注いでいる間ははっきり聞こえ、注ぎ終わるとすぐ小さくなって 10 秒ほどで消える
- ゴクッ（ひと口ごとの喉の音）・コポッ（喉に空気が入る音）。傾けて飲んでいる間に鳴るのはこの 2 つだけ
- カチン（乾杯）、コトッ（おかわり）

ブラウザの決まりで、最初にタップかキーを押すまでは音が出ません。

**省エネ。** 動いている間は低い解像度で描いて引き伸ばし、フレームが重ければ自動でさらに下げます。
傾けていないときは 2 フレームに 1 回だけ描きます。飲み干して止まったら描画を休みます。

## アクセス解析

公開ページでは、Cloudflare Web Analytics でアクセス数を数えています。Cookie を使わず、個々の訪問者を追跡しません（ページビュー・国・参照元・端末の種類などの集計だけ）。

- 計測のトークンは [XBill](https://github.com/Kawade502/xbill-webremake) と同じ（同じ `kawade502.github.io` のサイト）。Cloudflare の画面では「フィルタを追加 → パス」で `/beer-jug/` だけを見る
- 読み込むのは `kawade502.github.io` で開いたときだけ（`index.html` の最後）。手元の `vite`・`vite preview`・テスト・`?test` では数えない
- 開くたび（再読み込みを含む）に 1 ページビュー。広告ブロッカーを入れている人は数えられないので、実際より少なく出る

## 確かめ方

`?test` を付けて開くと描画ループが止まり、`window.__beer` から時間を進めたり傾けたりできます。
[`scripts/shot.mjs`](scripts/shot.mjs) は Playwright と Chromium のソフトウェア描画（SwiftShader）で、いくつかの場面を `shots/` に撮り、液量などの数値も書き出します。

```bash
npm run build && npx vite preview &
npm run shot   # playwright が別の場所にあるときは PLAYWRIGHT=… で渡す
```

共有用の画像は [`scripts/og.mjs`](scripts/og.mjs) が同じやり方で描いて、`public/og.jpg` に書き出します（できた画像はコミットします）。
泡が落ち着いたジョッキを右に寄せ、左に名前を入れます。X は画像の上下を少し切り、左下にタイトルを重ねます。そのため、まわりに余白を残しています。

```bash
npm run og     # 文字のフォントは FONT=…（woff2 など）で渡せる。今の画像は Zen Maru Gothic 700
```

```
scripts/
├── shot.mjs    場面ごとのスクリーンショット

```
